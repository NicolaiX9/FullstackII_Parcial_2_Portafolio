# FullstackII_Parcial_2_Portafolio
Portafolio React+Vite

Características:
Este es un portafolio profesional de prueba diseñado para la asginatura de Fullstack II. Está armado en React+Vite y utiliza elementos de Ant Design. 

Instrucciones:

Al clonar el repositorio es necesario instalar ciertas dependencias críticas mediante el comando "npm install" (sin las comillas) que, de no ser sugerido por el IDE que usted esté utilizando, podrá ser ejecutado en una terminal abierta manualmente por usted (ya sea abriéndola en el IDE mismo o haciendo click derecho y haciendo click en la opción "Abrir en Terminal" dentro de la carpeta donde guardó este proyecto). 

Tras instalar estas dependencias tiene dos opciones dependiendo de qué desee realizar:


1. Ver el portafolio:
   
Si desea ver el portafolio profesional debe abrir una terminal y ejecutar el comando "npm run dev" (sin las comillas). La terminal le entregará un link que usted debe abrir en un navegador de internet. 


3. Ejecutar los tests:

Para ejecutar los tests usted debe abrir una terminal y ejecutar el comando "npm run test". El resultado de los tests aparecerá en la misma terminal.
